How merge sort works

      
    
        
  1. Divide: split the array into two halves at the middle index.
    2. 
        
  2. Conquer: sort each half by calling merge sort on it (recursion). An array with one element is already sorted, so that's where the recursion stops.
    3. 
        
  3. Combine: merge the two sorted halves. Compare the front item of each half, copy the one that should come first (the smaller one for ascending, the larger one for descending) into the array, and move that half's pointer forward. When one half runs out, copy the rest of the other half.
    4. 
      

      

        
O(n log n)time in the best, average and worst case

        
O(n)extra space for the L and R copies

        
Stableequal values keep their order, because ties take from L first (<= for ascending, >= for descending)

      

      
Why n log n? Halving n elements until each piece has one takes about log₂ n levels (that's the height of the tree above). On every level, merging touches each of the n elements once. So the total work is about n × log₂ n.
